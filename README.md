# Агуулахын систем (Storage)

Ажилтнууд бараагаа зурагтай нь бүртгэж, ангилж, үлдэгдлээ хянах хялбар сервер. Гадны сан (dependency) шаардахгүй.

## Ажиллуулах

Node.js 22.5+ хэрэгтэй.

    node --experimental-sqlite server.mjs

Дараа нь http://localhost:3000 хаягаар нээнэ. Анхны үүсгэсэн бүртгэл нь супер админ болно.

## Боломжууд
- Супер админ ажилтнуудыг (ажилтан / админ эрхтэй) нэмж, хасна
- Бараа: зураг, ангилал, үнэ (заавал биш), нэгж (ширхэг / кг / метр), аравтын үлдэгдэл
- Бараа бүрт дуусах сануулгын хэмжээ; хяналтын самбарт дуусч байгаа / дууссан бараа, 7 хоногт хамгийн их гарсан бараа
- Хөдөлгөөний түүх: хэн, юуг, хэдийг авсан/нэмсэн
- Өгөгдөл `inventory.db` (SQLite), зураг `uploads/` хавтсанд хадгалагдана

PORT, DB_FILE, MAX_ITEMS орчны хувьсагчаар тохируулж болно.
